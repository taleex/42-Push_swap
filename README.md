# 42 - Push_swap

## Description:
push swap

## Operation Sets:

| Operation     | Description
| :---          | :---
| sa, sb, ss    | swap the top two elements
| pa, pb        | push the top of one stack onto the other
| ra, rb, rr    | rotate (top goes to the bottom)
| rra, rrb, rrr | reverse rotate (bottom goes to the top)
